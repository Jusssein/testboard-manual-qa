# Открытые вопросы и допущения

Вопросы зафиксированы при проектировании тестов по учебным требованиям и макетам. До выполнения проверок неоднозначное поведение требуется согласовать.

| Область | Вопрос | Связь с проверками |
| --- | --- | --- |
| Фотографии | Какие форматы и максимальный размер файла разрешены? | Подготовка фотографии для TC-07 и TC-09 |
| Количество объявлений | Есть ли ограничение числа объявлений одного пользователя? | Подготовка данных для публикации |
| Поиск | Как должен обрабатываться пустой запрос после очистки поля? | Возможное расширение поисковых проверок |
| Подгрузка | Когда начинается подгрузка при вертикальной прокрутке и какой индикатор должен отображаться? | TC-01 |
| Количество товара | Каковы минимальное и максимальное значения; разрешены ли дробные значения? | Подготовка корректных данных объявления |
| Сортировка | Предусмотрены ли варианты «Сначала новые» и «Сначала старые»? | Возможное расширение TC-03 |
| Описание | Как обрабатывается превышение 500 символов: ограничение ввода или ошибка при отправке? | TC-09 |

## Допущение для TC-09

Выбран вариант ограничения ввода: при вставке строки из 501 символа поле содержит 500 символов, 501-й не вводится; сохранение этих 500 символов разрешено при корректных остальных полях.

Это допущение определяет ожидаемый результат кейса и строки таблицы граничных значений. После уточнения требования оба артефакта обновляются согласованно.

## Подготовка окружения

- Для каждого кейса подготавливается указанное в нём состояние авторизации и набор объявлений.
- Для успешной регистрации используемый email должен отсутствовать в системе.
- В TC-17 после каждого варианта восстанавливается исходное состояние данных; выход из аккаунта сам по себе не освобождает зарегистрированный email.
- В TC-09 перед каждым вариантом создаётся новая форма с корректно заполненными остальными полями.
- Для проверки профиля заранее сохраняются персональные данные и известное изображение аватара.
