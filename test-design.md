# Артефакты тест-дизайна

Таблицы описывают выбранные сценарии из [21 тест-кейса](test-cases.md). Для каждого артефакта указана связь с кейсами. Таблицы решений охватывают проверяемые сочетания условий; дополнительные непроверенные сочетания здесь не перечисляются.

## Классы эквивалентности

**Связанные кейсы:** TC-01, TC-02, TC-03, TC-04, TC-20.

Данные группируются по ожидаемому поведению. Для поиска выбраны запросы с совпадениями и без совпадений; для сортировки — два предусмотренных направления. Карточка и профиль проверяются на представителях подготовленных доступных данных.

| Функциональность | Проверяемый класс | Представитель | Ожидаемый результат | Кейс |
| --- | --- | --- | --- | --- |
| Поиск | Запрос с совпадениями | «Пальто», варианты регистра | Одинаковая релевантная выдача | TC-01 |
| Поиск | Запрос без совпадений | «Северный единорог» | Заглушка отсутствия результатов | TC-02 |
| Сортировка | Возрастание цены | «Дешевле» | Цены по возрастанию | TC-03 |
| Сортировка | Убывание цены | «Дороже» | Цены по убыванию | TC-03 |
| Карточка | Существующее доступное объявление с заполненными данными | «Детская энциклопедия» | Отображение предусмотренных полей и фото | TC-04 |
| Профиль | Авторизованный пользователь с заполненным профилем | g.imanov@mail.ru, подготовленные имя, фамилия, дата и аватар | Данные соответствуют текущему аккаунту | TC-20 |

## Анализ граничных значений

**Связанные кейсы:** TC-09, TC-17.

Для верхней границы длины описания выбраны значения на единицу ниже, на границе и на единицу выше. Для минимальной длины пароля применяется тот же подход. При проверке паролей сохранены заглавная буква, строчные буквы и цифры; подтверждение совпадает с паролем.

| Поле | Ограничение | Значение | Пример | Ожидаемый результат | Кейс |
| --- | --- | --- | --- | --- | --- |
| Описание | Не более 500 символов | 499 | 499 повторений «А» | Полностью вводится и сохраняется | TC-09 |
| Описание | Не более 500 символов | 500 | 500 повторений «А» | Полностью вводится и сохраняется | TC-09 |
| Описание | Не более 500 символов | 501 | 501 повторение «А» | По принятому допущению вводятся и сохраняются 500 символов; 501-й не вводится | TC-09 |
| Пароль | Не менее 8 символов | 7 | Gim1234 | Отказ: «Пароль должен содержать минимум 8 символов» | TC-17 |
| Пароль | Не менее 8 символов | 8 | Gim12345 | Успешная регистрация | TC-17 |
| Пароль | Не менее 8 символов | 9 | Gim123456 | Успешная регистрация | TC-17 |

Каждый вариант выполняется в исходном состоянии. Для регистрации после успешного варианта восстанавливаются тестовые данные так, чтобы email снова был свободен.
